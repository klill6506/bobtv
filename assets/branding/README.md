# BobTV branding handoff

Shared home for branding work from every device.

- **artwork/** — logos, icons, backgrounds, splash-screen artwork, and editable source files.
- **sound/** — startup chimes, musical logos, and their editable source files.
- **concepts/** — alternate directions, mockups, and previews awaiting selection.

Upload through GitHub's **Add file → Upload files**, or pull this repository on your other device and commit/push your files. Pull before starting work so changes from other devices are included.

Use descriptive versioned names such as `bobtv-logo-teal-v1.svg` or `bobtv-startup-warm-v1.wav`. Keep alternatives instead of overwriting another device's work. Include a short note with the creator/source, usage rights, intended use, and which artwork and sound belong together.

SVG and transparent PNG are useful for logos; PNG/JPG for backgrounds; WAV for audio masters and MP3/OGG for playback previews. Keep individual uploads small; link to oversized editable projects rather than committing them.

Uploading here does **not** automatically change the live BobTV screen. Ken selects a direction, then we integrate it into the application. Current Bob Cinema audio is synthesized in `web/app.js`; there is no standalone sound file yet. Streaming-service logos remain in `web/brands/`.
